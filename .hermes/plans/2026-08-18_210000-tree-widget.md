# 我的空间树形 Widget 实现计划

> **目标:** 在 mindme-ai dashboard 新增 `dashboard-workspace-tree` widget，以可展开/折叠的树形结构展示用户注册的 workspace 及其根目录资源

**架构:** 
- 前端复用现有 `<Tree>` 组件 (`#/main/app/components/tree`)，后端扩展 `DashboardStatsManager` + `DashboardWidgetSerializer` 提供树数据
- 遵循现有 5 个 dashboard widget 的完整注册/序列化/样式链路，不引入新依赖
- Claroline 内置的 Tree 组件已生产验证（Lesson 插件使用），递归 `<ul>` 渲染 + `<Button type={LINK_BUTTON}>` 跳转

**Tech Stack:** React/Redux, PHP/Symfony, SCSS tokens (dashboard.scss)

**项目路径:** `/home/liuai/claroline/src/Claroline/src/integration/mindme-ai/`

---

## Premises（前提）

### 业务问题
用户在 mindme-ai dashboard 上看不到 workspace → 资源的导航树。需要手动切换到 workspace 工具列表，逐一点击查看。

### 验收标准
1. Dashboard 出现新 widget，标题"我的空间" / "My Workspaces"
2. 第一级列出当前用户注册了角色的所有 workspace（含 personal workspace）
3. 点击 workspace 展开第二级，显示根目录下用户有权限访问的资源
4. 初始全部折叠；资源上限 maxResources（默认 5 条）
5. 空 workspace 显示"暂无资源"
6. workspace 行点击 → 跳转 `/workspace/{slug}`；资源行点击 → 跳转资源详情页
7. 无 workspace 时 widget 隐藏（同 shortcuts widget 空状态模式）

### 明确不做（Scope Gate — 选择性）
- ❌ 不递归子目录资源（仅 parent=null 根目录）
- ❌ 不在 workspace/资源页面加 aside 树面板
- ❌ 不新建顶层 desktop tool
- ❌ 不增加排序字段（无 order/position，按 name 字母序）

**Step 3 — 新增 getWorkspaceTree() 方法**
```php
/**
 * Returns workspace tree for the current user.
 *
 * @return array{maxResources: int, tree: array}
 */
public function getWorkspaceTree(): array
{
    $user = $this->tokenStorage->getToken()?->getUser();
    if (!$user instanceof User) {
        return ['maxResources' => 5, 'tree' => []];
    }

    $max = $this->config->getParameter('mindme_ai.dashboard.workspace_tree_max_resources') ?? 5;
    $userRoles = $user->getRoles();

    // Same finder approach as WorkspaceController::listRegisteredAction
    $workspaces = $this->om
        ->getRepository(Workspace::class)
        ->findByFilters(['roles' => $userRoles, 'model' => false, 'personal' => 'any']);

    // Alternative: direct DQL if findByFilters doesn't exist
    // Let's use the CRUD Finder which is the standard way
    $finder = FinderProvider::getFinder(Workspace::class);
    $wsResult = $finder->find(
        FinderRequest::create()->addFilters([
            'roles' => $userRoles,
            'model' => false,
            'personal' => 'any',
        ])
    );
    $workspaces = $wsResult->getData();

    $authChecker = ...; // AuthorizationCheckerInterface via DI or setter

    $tree = [];
    foreach ($workspaces as $ws) {
        $rootResources = $this->om
            ->getRepository(ResourceNode::class)
            ->findBy([
                'workspace' => $ws,
                'parent' => null,
                'active' => true,
            ], ['name' => 'ASC']);

        $accessible = [];
        foreach ($rootResources as $res) {
            // Check user has OPEN permission
            if ($authChecker->isGranted('OPEN', $res)) {
                $accessible[] = [
                    'id' => $res->getUuid(),
                    'name' => $res->getName(),
                    'type' => $res->getResourceType()->getName(),
                    'url' => '/workspace/'.$ws->getSlug().'/resources/'.$res->getSlug(),
                ];
            }
        }

        $tree[] = [
            'id' => $ws->getUuid(),
            'name' => $ws->getName(),
            'code' => $ws->getCode(),
            'url' => '/workspace/'.$ws->getSlug(),
            'resources' => $accessible,
        ];
    }

    return [
        'maxResources' => $max,
        'tree' => $tree,
    ];
}
```

```jsx
/*
 * dashboard-workspace-tree widget: collapsible tree of user workspaces
 * and their root-level accessible resources.
 *
 * data.tree[] is injected by the backend serializer. Empty tree → widget
 * hides completely (same pattern as shortcuts widget §3.6).
 */

import React, {useState} from 'react'
import {connect} from 'react-redux'
import {PropTypes as T} from 'prop-types'

import {trans} from '#/main/app/intl/translation'
import {selectors as contentSelectors} from '#/main/core/widget/content/store'
import {Tree} from '#/main/app/components/tree'

import {BlockHead} from '../../common/block'

const PREFIX = 'claroline-distribution-integration-mindme-ai-dashboard-dashboard-workspace-tree'

const WorkspaceTreeComponent = props => {
  const parameters = props.parameters || {}
  const data = parameters.data || {}
  const tree = Array.isArray(data.tree) ? data.tree : []
  const maxResources = data.maxResources || 5

  // Empty tree → hide widget completely (spec §3.6)
  if (0 === tree.length) {
    return null
  }

  const items = tree.map(ws => ({
    id: ws.id,
    label: ws.name,
    type: LINK_BUTTON,
    target: ws.url || '#',
    children: (ws.resources || []).slice(0, maxResources).map(r => ({
      id: r.id,
      label: r.name,
      type: LINK_BUTTON,
      target: r.url || '#'
    })).concat(
      (ws.resources || []).length > maxResources
        ? [{
            id: ws.id + '-more',
            label: trans('dashboard_workspace_more_resources', {}, 'widget'),
            type: LINK_BUTTON,
            target: ws.url || '#'
          }]
        : []
    )
  }))

  return (
    <section className={PREFIX} aria-label={trans('dashboard_block_workspace_tree', {}, 'widget')}>
      <BlockHead
        title={trans('dashboard_block_workspace_tree', {}, 'widget')}
        en="My Workspaces"
      />

      <Tree
        className="workspace-tree"
        items={items}
        size="sm"
      />
    </section>
  )
}

WorkspaceTreeComponent.propTypes = {
  parameters: T.shape({
    data: T.shape({
      tree: T.arrayOf(T.shape({
        id: T.string,
        name: T.string,
        code: T.string,
        url: T.string,
        resources: T.arrayOf(T.shape({
          id: T.string,
          name: T.string,
          type: T.string,
          url: T.string
        }))
      })),
      maxResources: T.number
    })
  })
}

const WorkspaceTree = connect(
  (state) => ({
    parameters: contentSelectors.parameters(state)
  })
)(WorkspaceTreeComponent)

export {
  WorkspaceTree
}
```

## 风险

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| FinderProvider 获取方式不确定 | 中 | 需要一个工作时，验证阶段卡住 | coder 可以 fallback 到 `$om->getRepository()` + 手动 join，用 `findByRolesQuery` |
| 资源权限检查（isGranted）在批量场景可能慢 | 低 | 列表打开稍慢 | 只查根目录（少量资源）；如有 N+1 问题则用 DQL 一次查出 |
| 翻译文件可能不存在（widget 域） | 中 | 编译通过但缺翻译 | coder 需确认翻译文件实际路径，兜底用 `platform` 域 |
| 容器 prod 环境构建缓慢 | 低 | 验证耗时 | 可在宿主机直接 `php bin/console`（如果 PHP CLI 可用） |
